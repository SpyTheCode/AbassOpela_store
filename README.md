# AbassOpela Store

An e-commerce store project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app), running on **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.

## Tech Stack

- [Next.js](https://nextjs.org) 16 (App Router) + React 19
- [TypeScript](https://www.typescriptlang.org/) 5
- [Tailwind CSS](https://tailwindcss.com) v4
- ESLint (`eslint-config-next`)

## Getting Started

Install dependencies (already installed if `node_modules` is present):

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Available Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Start the dev server (Turbopack) |
| `npm run build` | Create a production build |
| `npm start` | Serve the production build |
| `npm run lint` | Run ESLint |

## Project Structure

- `src/app/` — App Router pages and layouts
- `public/` — Static assets served at `/`
- `images/` — Store image assets (logo, products)
